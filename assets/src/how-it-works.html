How mdctx keeps an agent's context small
Your Markdown stays in your repo and in your Git history. mdctx only measures it — and tells you which part is worth loading.

Your repository

  • AGENTS.md
  • docs/02_CURRENT_STATE.md
  • docs/CHANGELOG.md
  • docs/archive/**
  • vendor/** generated
→

mdctx (read-only)

  • scan — biggest first
  • check — limits & health
  • tokens — startup / active
  • tasks · dupes
  • never stages, commits or pushes
→

Split into cost tiers

Startup docs — read every session1,969 tok
Active docs — on demand only314,761 tok
Ignored by rules — never counted6,057,225 tok skipped
The three totals mdctx tokens prints for one real repo (Laravel cloud + Chrome extension, 1,767 files skipped).

AI coding agent

  • less context spent per turn
  • fewer stale notes in the way
